# Tarcísio Bezerra Advocacia — versão para testes Vercel

Site estático (HTML/CSS/JS), sem etapa de build.

## Publicação
1. Extraia o ZIP.
2. Importe a pasta como novo projeto no Vercel ou publique via `vercel` dentro da pasta.
3. Framework Preset: **Other**. Build Command: vazio. Output Directory: vazio (raiz).
4. Abra o URL de preview e teste as imagens, navegação e WhatsApp em celular.

## Antes do domínio definitivo
- `robots.txt` bloqueia indexação enquanto o site está em testes. Substitua por `Allow: /` ao publicar definitivamente.
- Ative a caixa `contato@tarcisiobezerra.adv.br` no provedor de e-mail.
- Confirme com Tarcísio as áreas efetivamente atendidas e as regras profissionais aplicáveis.
- Configure URL canônica, imagem Open Graph absoluta e política de privacidade se necessário.
- As fotografias são imagens geradas por IA a partir de referências fornecidas; validar autorização de uso e fidelidade antes da divulgação.
